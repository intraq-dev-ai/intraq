# SaaS embedded analytics examples

SaaS teams can use intraQ as an embedded analytics foundation over product, subscription, usage, and customer success data.

## Example questions

- What is monthly recurring revenue by plan?
- Which customers are at risk based on usage drop?
- Which accounts expanded this month?
- How many customers churned this month?
- Which features are used most by active accounts?
- Which onboarding step has the biggest drop-off?
- What is support volume by customer segment?

## Useful fields

- account, user, workspace, plan, subscription, invoice, and payment identifiers
- event date, usage event, feature name, session count, active users, and seats
- MRR, ARR, expansion, contraction, churn, plan changes, and support volume

## Dashboard components

- MRR KPI
- churn and expansion trend
- usage health table
- feature adoption chart
- onboarding funnel
- account risk dashboard

## Trust checks

- Confirm the MRR and churn definitions before publishing dashboards.
- Confirm whether trials, paused subscriptions, failed payments, and free plans are included.
- Confirm account-level versus user-level aggregation.
- Confirm the reporting period and timezone.
