# Ecommerce analytics examples

Ecommerce reporting usually combines orders, products, channels, customers, discounts, refunds, and margin.

## Example questions

- What was revenue by channel this month?
- Which products have the highest gross margin?
- Which products are growing fastest compared with last month?
- Which discount codes generated revenue but reduced margin?
- Which customers churned this month?
- Which products are frequently bought together?
- What is refund rate by product category?

## Useful fields

- order date, order id, customer id, product id, SKU, category, and channel
- gross revenue, net revenue, discount, refund, tax, shipping, cost, and margin
- customer cohort, acquisition source, repeat order count, and churn flag

## Dashboard components

- revenue KPI
- channel revenue chart
- product margin table
- discount performance table
- refund rate chart
- repeat purchase trend
- bundle opportunity table

## Trust checks

- Confirm whether revenue includes tax, shipping, refunds, or discounts.
- Confirm whether date filters use order date, fulfillment date, or payment date.
- Confirm the churn definition before reporting customer churn.
- Confirm whether cancelled orders are excluded.
