# GitHub discovery checklist

Use this checklist when updating the public GitHub repository page.

## Repository description

Recommended short description:

```text
Source-available AI reporting and dashboard platform for self-hosted operational analytics.
```

## Topics


Optional topic:

```text
agentic-ai
```

Use `agentic-ai` only if the public repository is being positioned around autonomous multi-step AI planning. Otherwise, keep the topic list focused on BI, dashboards, SQL, and analytics.

## Social preview

GitHub social preview settings are configured in:

```text
Repository → Settings → General → Social preview
```

Use [`docs/assets/social-preview.svg`](assets/social-preview.svg) as the source artwork. If GitHub requires a raster upload, export it to PNG first.

Recommended preview text:

```text
IntraQ
Self-hosted AI BI
Natural Language SQL
Dashboard Builder
Embedded Analytics
```

## Discussions

Enable GitHub Discussions when you are ready to respond publicly. Suggested first categories:

- Announcements
- Ideas
- Q&A
- Show and tell

Pin a welcome post that asks users to share:

- what database they want to connect;
- what reporting workflow they want to replace;
- which dashboard or text-to-SQL use case they are testing.
